# T5 — COSMO-SAC open sigma-profile databases + independent gamma-inf / VLE pack

Task T5 (agents/BOARD.md, branch `agents-board`). Two deliverables:

1. Availability + licence audit of open sigma-profile databases (VT-2005; UD / NIST
   COSMOSAC), and which Stomato `cosmo_sac_ig` components they cover.
2. An independent validation pack (`pack.yaml` + `data.csv`) built from open
   experimental sources — NOT from Hsieh et al. (2014) Table 6 and NOT from the NIST
   COSMOSAC repository's own validation outputs.

All retrieval dates: **2026-11-04**. Sources were retrieved and read in full this
session; no value is transcribed from memory.

## Part 1 — Sigma-profile databases: availability and licences

### 1a. NIST COSMOSAC repository (github.com/usnistgov/COSMOSAC)

Cloned this session (2026-11-04, `git clone --depth 1
https://github.com/usnistgov/COSMOSAC.git`; README and both profile directories read
from the clone). The paper: Bell et al., "A Benchmark Open-Source Implementation of
COSMO-SAC", J. Chem. Theory Comput. 2020, 16(4), 2635-2646,
DOI 10.1021/acs.jctc.9b01016 (author list cited from the repository's own reference
to the paper, not re-verified against the publisher page).

**Code licence (read from `LICENSE` in the clone):** MIT, "Copyright 2018 United States
Secretary of Commerce, NIST", with the note "not subject to copyright in the USA.
Foreign Rights Reserved, Secretary of Commerce."

**Profile-data licence (read from `README.md` in the clone):** the `.cosmo` files in
`profiles/UD` and `profiles/VT2005` are "covered by less permissive licenses"; NIST
obtained BioVia permission to make them available "for academic, non-commercial use";
all other use requires contacting ian.bell@nist.gov. This matches the repo's committed
README text quoted in `docs/thermo-catalogue-plan.md` (checked 2026-11-02/03 there;
re-verified from the live clone here).

**`profiles/UD/Readme.txt` (read in the clone):** 2261 compounds, DMol3 (Accelrys/
BioVia Materials Studio), from Fingerhut et al., Ind. Eng. Chem. Res. 2017,
DOI 10.1021/acs.iecr.7b01360 — 1941 from the University of Delaware database + 320
generated by the Fingerhut authors (initial structures from DDBST). Terms: "This
database can be freely used for non-profit, academic purposes. Re-distribution of the
database without the concent [sic] of the authors is prohibited." (The Readme names
the UD database as an extension of the VT database with conformation corrections for
about 1/3 of compounds, per Xiong, Sandler & Burnett, Ind. Eng. Chem. Res. 2014,
53, 8265.)

Counts verified in the clone: `UD/complist.txt` has 2263 lines (header + 2262 rows;
`UD/cosmo/` holds 2261 `.cosmo` files); `VT2005/Sigma_Profile_Database_Index_v2.txt`
has 1433 lines (header + 1432 rows; `VT2005/Sigma_Profiles_v2/` holds 1432 files).

### 1b. VT-2005 database (Mullins et al. 2006)

Mullins, Oldland, Liu, Wang, Sandler, Chen, Zwolak & Seavey, "Sigma-Profile Database
for Using COSMO-Based Thermodynamic Methods", Ind. Eng. Chem. Res. 2006, 45, 4389,
DOI 10.1021/ie060600h. Also distributed by Virginia Tech at
https://design.che.vt.edu/Downloads/VT_Sigma_Profile_Databases.html (the VT download
page describes VT-2005 + VT-2006 solute databases, 1645 unique compounds across the
two). **No licence statement was found in the NIST repo's `profiles/VT2005/` directory
(verified: no README/LICENSE file there), on the VT download page, or in the paper's
open abstract — the distribution terms remain undocumented.** Same finding as
`docs/coverage-gaps.md` (checked 2026-11-03 there).

Search method: exact CAS substring match over `profiles/UD/complist.txt` and
`profiles/VT2005/Sigma_Profile_Database_Index_v2.txt` in the clone, plus name-based
cross-checks (e.g. "NITROGEN", "DINITROGEN", tab-delimited N2 fields) to rule out
naming variants. The N2 result is a true absence: nitrogen is simply not in either
database (the closest VT2005 inorganic-gas rows are N2O4/NF3/NCl3; UD has no N2 row).

**Licence verdict for the repo's constraint set:** UD profiles are usable for
non-commercial/academic use with redistribution restricted (read the terms from the
clone); VT2005 terms are NOT FOUND (undocumented). Either way the profiles are **not
redistributable in an open repo**, so a `cosmo_sac_ig` row must fetch/require profiles
user-side rather than shipping them — consistent with the catalogue plan's decision to
leave row 6 unbuilt. The N2 gap (and CO2's absence from VT2005) means gas-sweetening
pairs like CO2/MeOH or any N2-containing pair cannot run on VT2005 at all, and N2 pairs
cannot run on either database.

## Part 2 — Independent validation pack (`data.csv` + `pack.yaml`)

Exclusions honoured: nothing from Hsieh et al. (2014) Table 6 (Ind. Eng. Chem. Res.
53, 8265) and nothing from the NIST COSMOSAC repo's `validation_data.zip`/
`generate_validation_data.py` outputs (I did not open either beyond the file listing).

### Sources used (all open, all read this session)

1. **VLE, water + ethylene glycol and water + triethylene glycol (0.1 MPa isobars):**
   Chouireb, Crespo, Pereira, Tafat-Igoudjilene, Vega, Coutinho & Carvalho,
   "Measurement and Modeling of Isobaric Vapor-Liquid Equilibrium of Water + Glycols",
   J. Chem. Eng. Data 2018, 63(7), 2394-2404, DOI 10.1021/acs.jced.7b00945.
   Retrieved from the open Supporting Information
   https://pubs.acs.org/jceaax/article-supplement/1567794/pdf/je7b00945_si_001/
   (fetched in full, 2026-11-04). Transcribed: SI Table S1 (H2O + EG, 0.1 MPa column,
   17 points) and SI Table S3 (H2O + TriEG, 0.1 MPa column, 18 points) — x_H2O, T, and
   the paper's derived gamma_H2O. Reported uncertainties u(x)=0.001, u(T)=1 K,
   ur(p)=0.005. Note the paper's gamma_H2O are model-derived from boiling temperatures
   (indirect method), so pack.yaml uses only the directly measured T(x) as bubble_T
   targets; the tabulated gamma_H2O are kept in data.csv as reference rows flagged
   `gamma_H2O_finite_dilution` (they are experimental-data-derived, not model-fitted
   targets).
2. **gamma-inf, methanol in water (298.15/323.15/333.15 K):** Tochigi, Uchiyama &
   Kojima, "Measurement of Infinite-dilution Activity Coefficients of Alcohols in
   Water Using Relative Gas-liquid Chromatographic Method", Korean J. Chem. Eng. 2000,
   17(5), 502-505, DOI 10.1007/BF02707115. Full text openly retrievable at
   https://www.kiche.or.kr/journal/kjche/fulltext/17/5/502/e38a5dc0 (fetched in full,
   2026-11-04). Transcribed from Table 1, "non-ideal gas" gamma_inf column (methanol
   rows): 1.72 / 2.07 / 2.26. The paper also tabulates "ideal gas" variants
   (1.71 / 2.05 / 2.24); the non-ideal-gas column is transcribed as primary.
3. **gamma-inf, methanol in ethylene glycol (323/343/363/383 K):** Zhang, Tsuboi,
   Nakata & Ishikawa, "Infinite Dilution Activity Coefficients in Ethylene Glycol and
   Ethylene Carbonate", J. Chem. Eng. Data 2003, 48(1), 167-170. Retrieved via the
   open NIST ThermoML Converter dataset page
   https://www.stuchalk.domains.unf.edu/trc/datasets/view/016027 (fetched in full,
   2026-11-04), which renders the ThermoML record for the article: methanol gamma in
   1,2-ethanediol = 1.230 ± 0.047 (323 K), 1.241 ± 0.047 (343 K), 1.320 ± 0.052
   (363 K), 1.271 ± 0.049 (383 K) at P = 101.3 kPa, GLC method. The NIST ThermoML
   archive record for this article lives at
   https://trc.nist.gov/ThermoML/ (bulk archive DOI 10.18434/mds2-2422); the direct
   .xml fetch of the corresponding record URL did not return content this session
   (see NOT FOUND), so values are cited from the open ThermoML Converter page.

### Independence check

- Tochigi 2000 (MeOH/H2O): RGLC measurements against literature gamma-infinity
  references; no Hsieh-2014 or NIST-COSMOSAC connection.
- Zhang 2003 (MeOH/MEG): independent JCED GLC measurements, distributed through
  NIST's ThermoML data pipeline (the *data archive*, not the COSMOSAC *benchmark
  outputs*). Not part of anything COSMO-SAC was fitted to.
- Chouireb 2018 (H2O+MEG, H2O+TEG): independent ebulliometric measurements used in
  the original papers to fit CPA/PC-SAFT-type models, not COSMO-SAC.

### What is in the pack

- `data.csv` — one row per point: 7 gamma_inf rows (MeOH/H2O x3, MeOH/MEG x4), 2
  derived-gamma reference rows, 35 bubble_T rows matching the pack.yaml cases. Every
  row carries source citation, URL, table, and retrieval date.
- `pack.yaml` — 35 bubble_T cases (17 for H2O+MEG, 18 for H2O+TEG, all at 100000 Pa)
  in the standard case schema, `package: pending:cosmo_sac_ig`, tolerance
  bubble_T 0.5 % (P1-05 convention).

### NOT FOUND / gaps (where I looked)

- **gamma-inf, H2O in MEG / H2O in TEG / MeOH in TEG / MeOH in DME / DME systems:**
  NOT FOUND as open numeric tables. Searched NIST ThermoML (trc.nist.gov/ThermoML
  search + bulk archive DOI 10.18434/mds2-2422 described at
  https://www.nist.gov/data-publications/thermomldata-archive), open JCED supplements
  and open-access journals. Closest open hits are the JCTC-paywalled 2013 J. Chem.
  Thermodynamics paper (Topphoff-style GLC in DEG/TEG, DOI 10.1016/j.jct.2013.05.011 —
  paywalled) and the 1967 Kagaku Kogaku Japanese-language paper on water in glycerol/
  TEG (DOI 10.1252/kakoronbunshu1953.31.1067 — scanned tables not machine-retrievable
  this session). The harness also has no gamma-inf expected key yet, so gamma-inf rows
  are reference data, not executable cases (see pack.yaml header).
- **MeOH + DME binary VLE (open, experimental):** NOT FOUND. Searched ThermoML
  (trc.nist.gov), JCED open supplements, Fluid Phase Equilibria open access; DME VLE
  papers found are paywalled or gas-solubility-only. Recorded as a gap rather than
  substituting estimated values.
- **N2 sigma profile:** NOT FOUND in either database (both index files grepped by CAS
  and name, see Part 1c) — a permanent gap for N2-bearing pairs, not a retrieval
  failure.
- **VT2005 licence text:** NOT FOUND (no licence file in profiles/VT2005/, none on the
  VT download page). Treat VT2005 as unlicensed-for-redistribution until VT states
  terms.
- **Direct raw ThermoML XML for the Zhang 2003 and Aniya 2015 articles:** the record
  pages (https://trc.nist.gov/ThermoML/10.1016/j.fluid.2015.07.030.html and the
  analogous JCED record) render summaries/datasets via the web interface; a direct
  fetch of the `.xml` path returned empty content this session, so numeric values were
  taken from the rendered dataset page (Zhang) and the open ACS SI (Chouireb). The
  Aniya 2015 water+TEG data (60 T-x-y points at 53.33-95.99 kPa per the record page)
  is an identified backup source if more sub-atmospheric points are wanted.
