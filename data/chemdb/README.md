# Chemical database (`data/chemdb/`)

Generated by `scripts/chemdb/` from the sources in `sources.yaml`, read through
`ngdesign.data.chemdb`. Do not edit these tables by hand; change the build and rerun
it, so every value stays traceable. `MANIFEST.json` has the counts and the versions
of one build. Nothing in here is estimated or predicted: a row is a number a named
source states, converted to SI.

| File | Content |
|---|---|
| `species.csv` | Identity: CAS, name, IUPAC name, Hill formula, MW, charge, InChIKey, connectivity SMILES, PubChem CID; `identity_source`, and `live_nist` = 1 when a WebBook page was fetched for it |
| `properties.csv` | Long table, one row per stated value: `cas, property, value, unit, uncertainty, T_K, source, grade, reference, selected` |
| `janaf.csv` | Full NIST-JANAF tables of neutral species: Cp, S, H−H298, ΔfH, ΔfG, log Kf against T |
| `shomate.csv` | NIST Shomate coefficients by phase and T window |
| `antoine.csv` | Antoine fits, normalised to log10(P/bar) = A − B/(T/K + C), with T windows |
| `wagner.csv` | Wagner vapour-pressure fits (forms 2.5-5 and 1.5-3-6) |
| `cp_gas.csv` | Ideal-gas Cp fits (Poling polynomial, TRC eight-term) |
| `cp0_eos.csv` | Ideal-gas Cp0 of CoolProp's reference equations of state, one row per term (constant, Planck-Einstein, Aly-Lee cosh, power), each row citing its EOS paper |
| `cp_gas_points.csv` | Stated gas Cp(T) points: WebBook gas heat-capacity tables (`nist`, the table's reference per row) and pure-compound ideal-gas Cp from the NIST ThermoML archive (`thermoml`, article and method per row) |
| `sources.yaml` | Full citation for every `source` key |
| `AUDIT.txt` | Where non-estimated sources disagree beyond the audit limits |

## Properties

`Hf_gas|liquid|solid|aq`, `Gf_*`, `Hc_*` (formation and combustion, J/mol, 298.15 K, 1 bar), `S0_*`, `Cp_*` (J/(mol K)),
`Tb`, `Tm`, `Tt`, `Tc` (K), `Pt`, `Pc` (Pa), `Vc` (m3/mol), `Hvap` (at `T_K`),
`Hvap_298`, `Hsub_298`, `Hfus` (J/mol), `rho_liquid` (kg/m3).

`Hf_aq`, `Gf_aq`, `S0_aq`, `Cp_aq` use the 1 molal standard state with H+(aq) = 0. Ions come
from the CRC table. Dissolved gases are derived, by definition and without estimation,
from a gas's selected values and WebBook Henry's-law data; their rows say so in `reference`.
Sander's compilation as packaged in `thermo` (rank below the WebBook) disagrees for ammonia:
42.7 mol/(kg bar) against the WebBook median 58. The compilation's own reviewed entries
(v5.0.0, 2023: 0.59 mol/(m3 Pa), about 59 mol/(kg bar)) side with the WebBook, and a test
holds the selection to them.

## Grades and selection

All stated values are kept. For each (species, property) one is flagged `selected`:

| Grade | Meaning | Sources, in selection order |
|---|---|---|
| A | Evaluated or critically reviewed | CoolProp reference EOS (Tc, Pc only), ATcT, NIST-JANAF, IUPAC critical series, WebBook rows with method "Review" |
| B | Handbook compilation, or a referenced measurement | CRC Handbook tables, Poling, WebBook measurements and TRC averages, the WebBook snapshot |
| C | Compilation without a per-value reference | Yaws |

Ties within a source go to the smaller stated uncertainty, then the newer reference.

Rank alone is not trusted for Tc, Pc, Tb and Tm. With at least three sources, a value
far from their median is set aside for the best-ranked one near it, and the swap is
logged at the top of `AUDIT.txt`. This is not hypothetical: the bundled IUPAC table
exchanges cyclohexane and methylcyclopentane. Both rows stay in `properties.csv`,
unselected. A polymorph-rich species keeps the JANAF table with the lowest G°298.

Two physical tests then catch what no vote can. A condensed phase must lie below its gas
by a plausible phase-change enthalpy, which catches sign slips in a source (the CRC table's
CI4 and CHI3 solids), and a stated Tb must agree with a vapour-pressure fit at 1 atm. A
failing selection moves to the best-ranked row that passes, and the move is logged.

## Rebuilding

Downloads go to a cache directory outside the repo, and only parsed numbers are
committed. The fetcher honours the WebBook's `Crawl-delay: 5` and PubChem's rate limit.

```bash
python -I scripts/chemdb/fetch.py nist    seed.txt  CACHE    # seed: one CAS per line
python -I scripts/chemdb/fetch.py janaf   CACHE
python -I scripts/chemdb/fetch.py thermoml CACHE           # 190 MB, SHA-256 checked
python -I scripts/chemdb/build.py seed    CACHE              # writes CACHE/cids.tsv
python -I scripts/chemdb/fetch.py pubchem CACHE/cids.tsv CACHE
python -I scripts/chemdb/build.py tables  CACHE data/chemdb
```

NIST data are © U.S. Secretary of Commerce and used here with citation; PubChem and
the bundled tables are cited in `sources.yaml`.

## Known gap: ideal-gas Cp(T) for large organics

About 2,850 species state ΔfH° and S° for the gas but have no cited Cp(T), so they have no
gas model beyond a narrow constant-Cp window. These sources were checked:

| Source | Outcome |
|---|---|
| NIST-JANAF, NIST Shomate (crawled and snapshot), TRC, Poling | used; they do not cover these species |
| NASA CEA, NASA/TP-2002-211556 (Apache-2.0) | used; mostly combustion species, adds 67 gas models here |
| WebBook tabulated gas Cp(T) | 10 of these species; most tables start at 380-600 K with no 298 K point to anchor on |
| WebBook pages not yet crawled (2,649 of them) | a random sample of 60, fetched 2026-11-02, carried no gas Shomate fit and no gas Cp table, so the rest were not crawled |
| Burcat & Ruscic, ANL-05/20 | refused: its terms forbid inclusion in non-free software, and this repository is proprietary |
| psi4 characteristic temperatures in `chemicals` (2022a) | refused: computed inside that library, with no external publication to cite |
| Joback group contributions | refused: an estimation method, not stated data |
| Ideal-gas parts of CoolProp's reference EOS (MIT; each EOS paper cited per row) | used, 2026-11-03: Cp0(T) for 124 species in `cp0_eos.csv`. It is the gas shape only where no JANAF, Shomate, NASA or TRC/Poling fit exists. That completes the gas model of 7 species: hexamethyldisiloxane, methyl oleate, propylene glycol, R236ea, R236fa, R245ca, R245fa. Another 26 (siloxanes, methyl esters, HFOs, dimethyl carbonate) now have Cp0 but still no ΔfH°. Of the 91 species that have both, 87 agree within 2 %. The 4 that do not (1,2-dichloroethane +6.1 %, CF3I −5.5 %, perfluorobutane +7.8 %, dimethyl ether +2.2 %, all relative to TRC or JANAF) are listed in `AUDIT.txt`. Their tabulated source stays the selected shape, and the cause was not resolved here |
| ATcT 1.222 (Argonne; DOE PuRe resource) | not added: atct.anl.gov sits behind a Cloudflare challenge that blocks scripted fetches, and its Wayback copies were offline on 2026-11-03. ATcT 1.112 already enters through `chemicals` |
| NIST CCCBDB (SRD 101) | not pursued: its experimental Cp is a single 298.15 K value per species, and its species are the small molecules JANAF and TRC already cover |

Closing the gap needs a licensable evaluated compilation (DIPPR 801, TRC Thermodynamic Tables)
or published measurements per species.
