Part of #210 (round-1 column-shortcut family). Carries the round-1 review fixes: Underwood bracket on (1, alpha_LK), book-rounding V1 tolerances with assessed misses, and the two V2 comparisons against the rigorous MESH column.

## Why

The round-1 column work needs shortcut (R0) column adapters so flowsheets can estimate staged columns before committing to a rigorous MESH solve. This PR ships the four U-E R0 units with cited validation, and the round-1 review corrections on top: the Underwood root was bracketed on the wrong interval (a light non-key above the light key could capture the root), the FUG V1 tolerances had been widened after measuring, and the spec-mandated V2 MESH comparisons were missing.

## What changed

- Four R0 adapters in `src/ngdesign/units/column_shortcut/`, one executable spec:
  - `distillation.py` — shortcut (FUG) distillation: Fenske Nmin, Underwood Rmin (heavy-key-relative alphas), Gilliland, Kirkbride split, iterative non-key distribution on seeded K-values, condenser/reboiler duties.
  - `_kremser.py` + `absorber.py` — Kremser absorber (Seader–Henley Example 5.3 basis).
  - `stripper.py` — reboiled Kremser stripper (Example 9.8).
  - `extractor.py` — constant-distribution-coefficient extractor (Example 5.2, mole-basis K_D).
  - `src/ngdesign/units/_physics/shortcut.py` — pure correlations (Fenske, Underwood, Gilliland, Kirkbride, Kremser incl. inversion), no adapter dependencies.
- Review fix (blocking): `underwood_theta` now takes the light key's alpha and brackets the Class-2 root on **(1, alpha_LK)** instead of (1, max alpha). The old bracket let a light non-key above the light key capture the root (measured over 171 four-component cases with a light non-key: 118 roots outside the key interval, 18 ZeroDivisionError on a midpoint landing exactly on the alpha_LK pole). Any finite feed quality is accepted (subcooled q > 1 and superheated q < 0 — the Underwood equation holds for any finite q); a distributing component strictly between the keys is refused by name. Regression tests cover all of these.
- Review fix: V1 FUG tolerances are the book's printed rounding (two decimals on Nmin, three on Rmin) and are never widened; the measured Peng-Robinson deviations are recorded as an assessed miss with numbers and cause.
- Review fix: the two V2 comparisons against the existing rigorous `column` MESH unit (spec U-E V2) — see the table below.
- Review fix: the extractor accepts one distribution-coefficient param name — `K_D` or the absorber-style `k_overrides` alias; giving both is refused (alias equivalence tested).
- Review fix: any finite feed quality accepted by the Underwood solve; the R0 condenser-duty approximation (overhead vapour condensed at the distillate composition, not the top-tray composition) is documented in the `shortcut_distillation` row notes; tests live in `tests/units/column_shortcut/` and the unused type-ignore is gone.
- Catalogue: four `column.yaml` R0 rows made provisional with adapter paths, param schemas, and `validation` ids; docs regenerated.

The Kremser miss cause: the R0's documented absorption factor uses the inlet flows (A = 0.842/0.787) while the converged column's effective mid-column factor is L_mid/(K·V_mid) = 0.882/0.872 (L grows ~8 % with absorbed C3, V falls ~2 %). The Kremser form itself agrees with the MESH to +0.2 % (N=2) / −0.6 % (N=4) when evaluated at the MESH's own mid-column A.

## Documented deviations / stand-ins

- Butadiene sulfone is not in the component database: the stripper case uses documented n-decane as the sulfone stand-in (noted in the row and case).
- Extractor Example 5.2: the book's mass-ratio K′D = 1.2 is converted to a mole-basis K_D = 5.2027 using registry molar masses; the case reproduces the printed 89.1 %.
- Some printed outlet-flow figures in Examples 5.3/9.8 are inconsistent; cases anchor on the printed component fractions, which do reproduce.
- Extractor R0 assumes immiscible carriers; non-solute components route wholly with their inlet phases.
- R0 condenser duty condenses the overhead at the distillate composition (h at its dew T minus h at its bubble T); a real total condenser's vapour carries the top-tray composition, which R0 does not track (row note).

## Tradeoffs

- The V1 FUG case runs on the engine's Peng-Robinson package rather than the book's K-chart K-values: transcribing the book's printed K-table was rejected because those values could not be read and verified from an accessible source this round. The price is the assessed Nmin/Rmin miss recorded in the case; driving the case with verified book K-values via `k_overrides` would close it.
- The Kremser V2 comparison feeds the R0 absorber the converged MESH's mid-column K-values (the same basis the P1-09 oracle evaluates) because the PR package gives no K-values at the single-phase gas-in condition; the residual gap is the R0 inlet-flow A basis, recorded as a measured miss rather than absorbed by a wider band.
